# Finish

Craft is the sum of many small upgrades.

- **Replace stock defaults where a custom version adds meaning.**
  - bullets → checkmarks or topic icons
  - testimonial quotes → large, colored quote marks as a visual element
  - links → a custom underline (offset, thickness)
  - checkboxes and radios → the brand color via `accent-color`

  Values: `references/components.md` (Finishing).
- **Add color with accent strokes, not more elements.** A thin colored bar marks the active nav item, tops a featured card, edges an alert, or sits under a section heading.
- **Give long pages surface variety.** Alternate section backgrounds, a subtle single-hue gradient (hues within about 30°), a low-contrast pattern or fine noise, or simple shapes, always behind the content.
- **Rethink stock components.** Selects with groups, icons, and descriptions; table cells that combine a name, its email, and an avatar; radio groups as selectable cards; inline hover previews.
- **Polish the interaction.** Nearly every interactive element gets a small hover and press response; add one delightful moment (an empty state, a 404) rather than many.
- **Give copy and motion the same care as pixels.** Copy says how the product helps; motion uses the tokens.

**Check:** Is any component still at a library or browser default where a custom version would add meaning?
