# Finish

Craft is the sum of many small upgrades.

- Replace stock defaults where a custom version adds meaning:
  - bullets with checkmarks or topic icons
  - testimonial quotes with large, colored quote marks as a visual element
  - links with a custom underline (offset, thickness)
  - checkboxes and radios with the brand color via `accent-color`

  Values: `references/components.md` (Finishing).
- Add color through accent strokes. A thin colored bar marks the active nav item, tops a featured card, edges an alert, or sits under a section heading, without adding an element.
- Vary the surface on long pages. Alternate section backgrounds, or use a subtle single-hue gradient (hues within about 30°), a low-contrast pattern or fine noise, or simple shapes, always behind the content.
- Rethink stock components: selects with groups, icons, and descriptions; table cells that combine a name, its email, and an avatar; radio groups as selectable cards; inline hover previews.
- Nearly every interactive element gets a small hover and press response. Add one delightful moment (an empty state, a 404) rather than many.
- Copy and motion get the same care as pixels. Copy says how the product helps, and motion uses the tokens.

**Check:** Is any component still at a library or browser default where a custom version would add meaning?
