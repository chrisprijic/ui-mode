# Nudge

Design for how people really decide, using only **honest levers**.

- Keep every lever honest. An honest lever is one whose every claim is true and current: counts, ratings, stock, deadlines, former prices. Declining is as easy and as visible as accepting, with neutral copy ("Not now"). Paid extras start unselected, and a preselected plan shows its price, billing cadence, and how to cancel inside its own option.
- Most people keep defaults and read them as recommendations, so pre-fill the option that serves most users.
- Show real progress (goal gradient). Count the steps already done: if creating the account was step 1 of 4, the bar starts at 25%. Name the steps.
- Give value before asking (reciprocity). Show a real partial result (the score, the first findings, what passed), then ask for signup to save it or see the rest. A blurred result behind a wall is a **tell**.
- Let users invest first (IKEA effect). They name, configure, or pick something before the account step, and that step is labeled "Continue".
- Make stakes concrete (loss aversion). On downgrade and retention screens, list the user's own items that will be affected. Count down only to a real deadline.
- Put each cost beside its reference (anchoring). An add-on sits under the item it covers, with its relative cost ("+4% of your order"), and a genuine former price can sit beside the current one.
- State the downside before the user finds it. A trial timeline, for example, shows the reminder day and the charge day.
- Calls to action are light and owned: sentence case, first person where it fits, and specific ("Start my free trial", "Place order · $48.20").
- Make social proof specific, like "4.8 · 1,240 reviews" instead of five bare stars.

**Check:** List every lever on the screen. Is each claim true today? Can the user decline in one neutral tap? Is anything paid preselected without its terms in view?
