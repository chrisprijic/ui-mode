# Subtract

Use the fewest elements that make the point, without removing what the decision needs.

- **Delete what isn't earning its place.** Common freeloaders:
  - labels the layout already implies
  - divider lines and strokes
  - arrows that repeat a gesture
  - a second control doing the same job
  - cards that only hold a title
  - a second, competing call to action
  - decorative glow and multi-hue gradients
- **Separate with space before lines.** In order of preference: more space, a background shift, a shadow, then a border. Values: `references/layout.md` (Separation).
- **Keep surviving borders quiet.** Use the `border` token, a low-contrast neutral, rather than a dark hairline. Values: `references/color.md` (Neutrals).
- **Context isn't clutter.** An illustration that tells a first-time visitor what the product does earns its space; one more ornament beside it doesn't.
- **Merge modules that describe one thing.** A growth figure belongs inside the revenue chart, not in its own card. Cut features foreign to the domain.
- **Offer fewer, clearer choices (Hick's law).** Three or four plans; three to five tabs.
- **Subtract from the screen, not from the decision.** Before removing something, check whether the user weighs it when choosing (**Decide**).

**Check:** For each element, what breaks if you delete it? If nothing, delete it. If the decision gets harder, keep it.
